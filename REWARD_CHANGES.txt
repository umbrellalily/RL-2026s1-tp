[문제 진단] demo_strict_91.gif 분석
--------------------------------------------------------------------------------
- 형태 "D"(GROUND->D->G의 1단계) 형성 중, 14칸 중 5칸만 점등되고 나머지 드론은
  비어 있는 타깃칸의 "정확히 한 칸 옆/아래"에서 멈춤.
- step ~100 이전에 이 상태에 도달한 뒤 step 500(timeout)까지 픽셀 단위로 동일.
  즉 ~400스텝 동안 단 한 칸도 안 움직이고 얼어붙음.
- 충돌/배터리가 아니라 TIMEOUT(완성 실패). 빈칸인데도 마지막 한 스텝을 안 밟음.

원인 가설:
  1) 목표 인접(거리 1)에서 마지막 한 스텝의 유인이 너무 약함 + greedy argmax 국소최적.
  2) on_target_reward가 "아무 점등칸"에 주어져, 자기 칸이 아닌 칸에 눌러앉는(camping)
     경향. 완성 보상(+50)은 지연·공유 보상이라 개별 드론은 움직일 유인이 약함.
  3) 커버리지 보상이 "최고기록 갱신 시 1회"만 지급되어, 마지막 빈칸을 채우려는
     상시 압력이 없음.

[적용한 변경] (충돌 패널티 인하는 의도적으로 제외 — 충돌로 인한 실패도 있기 때문)
--------------------------------------------------------------------------------

(1) 상시 커버리지 보상 신설  [구조적 핵심 수정]
    - 파일: comm_env.py (ShapeFormationEnv.__init__, step)
    - 신규 파라미터: coverage_step_reward (env 기본값 0.0 = 하위호환, 미사용 시 영향 없음)
    - 동작: 매 스텝, 모든 드론에게 += coverage_step_reward * (현재 점유된 타깃칸 수)
    - 기존 coverage_delta_reward(최고기록 갱신 시 1회)와 달리 "매 스텝" 지급.
      => 빈칸 1개가 매 스텝 팀 전체의 손해가 되어, 마지막 칸을 "채우고 유지"하려는
         상시 압력이 생김. (얼어붙음 직접 대응)
    - 학습 스크립트 기본값: 0.01
      (예: 14칸 만점이면 +0.14/step, 한 칸 더 채우면 남은 스텝 동안 +0.01/step씩
       팀 전원에게 지속 지급 → 마지막 칸 진입의 가치가 커짐)

(2) 자기-배정칸 보상 인상  [캠핑 억제 + 마지막칸 유인 강화]
    - 파일: comm_train.py, comm_train_battery.py (argparse 기본값)
    - --assigned-target-reward 기본값: 0.3 -> 0.4
    - 자기 배정칸 점유 = on_target(0.1) + assigned(0.4) = 0.5/step.
      엉뚱한 점등칸 캠핑(0.1/step)보다 확실히 이득 => 자기 칸으로 가도록 유도.

(3) 엔트로피 계수 인상  [탐험↑, "정지" 국소최적 탈출]
    - 파일: comm_train.py, comm_train_battery.py (argparse 기본값)
    - --ent-coef 기본값: 0.01 -> 0.02

(참고) shaping_coef: 변경 없음(유지). collision_penalty: 변경 없음(요청대로 제외).

[!!! 매우 중요 — Colab에서 실제로 적용되게 하려면 !!!]
--------------------------------------------------------------------------------
colab runner의 설정 셀(셀 8)이 아래 두 값을 "명시적으로" 학습 명령에 넘기므로,
스크립트 기본값을 바꿔도 colab 값이 우선합니다. 따라서 셀 8에서 직접 바꿔야 함:

    ASSIGNED_TARGET_REWARD = 0.1   ->  0.4   (변경 필요)
    ENT_COEF               = 0.01  ->  0.02  (변경 필요)

반면 --coverage-step-reward 는 colab이 넘기지 않으므로 새 기본값 0.01이
"자동 적용"됩니다. 만약 값을 조절하고 싶으면 학습 명령에 아래를 추가:

    --coverage-step-reward {COVERAGE_STEP_REWARD}

그리고 셀 8에 COVERAGE_STEP_REWARD = 0.01 (또는 원하는 값) 추가.

요약:
  - coverage_step_reward = 0.01  -> 코드 기본값으로 자동 적용 (colab 수정 불필요)
  - assigned_target_reward = 0.4 -> 셀 8에서 0.1 -> 0.4 로 직접 수정 필요
  - ent_coef = 0.02              -> 셀 8에서 0.01 -> 0.02 로 직접 수정 필요
